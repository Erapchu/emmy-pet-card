# Сайт-паспорт Эмми

Статический мобильный сайт в Docker с автоматическим HTTPS через Caddy.

## 1. Подготовьте домен

Создайте DNS-запись типа `A`:

- имя: `emmy` или `@`
- значение: публичный IPv4 вашего VPS

Например, для адреса `emmy.example.com` запись будет `emmy -> 203.0.113.10`.

Если у VPS есть IPv6, добавьте также запись `AAAA`.

## 2. Настройте сайт

1. В `Caddyfile` замените `emmy.example.com` на настоящий домен.
2. В `site/data.json` укажите телефон, Telegram, WhatsApp и сведения об Эмми.
3. Положите фотографию в `site/emmy.jpg`.
4. Не публикуйте точный домашний адрес, паспортные данные и другие лишние персональные сведения.

## 3. Запустите на VPS

Установите Docker и Compose, затем выполните:

```bash
docker compose up -d
```

Проверьте:

```bash
docker compose ps
docker compose logs -f emmy-site
```

Caddy автоматически получит и обновит TLS-сертификат, если:

- DNS уже указывает на VPS;
- порты 80 и 443 доступны из интернета;
- домен правильно указан в `Caddyfile`.

## 4. Обновление данных

Отредактируйте `site/data.json`. Перезапуск контейнера обычно не нужен — обновите страницу в браузере.

## 5. QR-код

QR-код должен содержать только постоянный HTTPS-адрес, например:

```text
https://emmy.example.com
```

Не кодируйте телефон и подробности прямо в QR: сайт можно обновлять, а жетон останется прежним.

Для жетона используйте короткий домен, высокий контраст и коррекцию ошибок QR уровня Q или H. Рядом напишите обычным текстом телефон — камера или интернет могут не работать.
